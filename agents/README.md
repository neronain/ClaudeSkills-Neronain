# Agents

Specialized AI agents for specific tasks.

## Agents

| Agent | Description |
|-------|-------------|
| [security-auditor](./security-auditor.md) | Security audit specialist - vulnerabilities, OWASP, compliance, pentest |

## Available Audit Types

- `code` - Code review for security issues
- `deps` - Dependency vulnerability check
- `secrets` - Secret detection in repo
- `compliance` - Compliance framework check (GDPR, PCI-DSS)
- `pentest` - Penetration testing simulation
