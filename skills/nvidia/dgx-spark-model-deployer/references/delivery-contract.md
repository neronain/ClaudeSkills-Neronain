# Delivery Contract

Deliver:

1. recommendation;
2. exact model, revision, runtime, and topology;
3. individual files;
4. ZIP;
5. package checksums;
6. installation commands;
7. first-run sequence;
8. test sequence;
9. client settings;
10. limitations;
11. static versus hardware validation status.

The README must include:

```text
requirements
persistent paths
runtime pin
download and verification
conflict shutdown commands
start after reboot
status and logs
feature tests
context tuning
security
validation scope
```
