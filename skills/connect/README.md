# Connect Skills

Connect Claude to 500+ SaaS applications via Composio.

## Skills

| Skill | Description |
|-------|-------------|
| [connect](./SKILL.md) | Connect to Gmail, Slack, GitHub, Notion, Jira, Asana, Trello, Linear, and 500+ more |

## Integrations Available

- **Communication**: Slack, Gmail, Discord, Telegram, Outlook
- **Project Management**: Jira, Asana, Trello, Linear, ClickUp, Notion
- **Development**: GitHub, GitLab, Bitbucket
- **CRM**: HubSpot, Salesforce, Pipedrive
- **Storage**: Google Drive, Dropbox, OneDrive
- **Analytics**: Google Analytics, Mixpanel, Amplitude
- **E-commerce**: Shopify, Stripe
- **Calendar**: Google Calendar, Calendly

See [Composio Docs](https://composio.dev/tools) for full list.
